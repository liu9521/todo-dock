待办胶囊 · 使用说明

桌面右下角常驻的小胶囊，点开是最近待办 + 月历。支持两类待办： 带日期的日程（当天 / 提前一天提醒）和不设日期的近期待办。 胶囊第二行实时显示浙商银行积存金价格。待办数据全部存在本机；只有金价读取一个公开行情接口。

一、折叠态小胶囊

第一行
待办总数 · 今日几条 · 近期几条 · 日期，像输入法状态栏一样贴在任务栏上方。
第二行
浙商金 841.82 元/克 ▲ +1.06% 11:18（浙商银行积存金实时价、涨跌幅、报价时间）。 涨用红色、跌用绿色（A 股习惯，价格数字和 涨跌幅一起染色、涨跌粗体）。每 5 秒自动刷新，点这一行可立即刷新； 断网时继续显示上次报价，时间后带 * 标记。
点第一行
展开面板；点面板外或「收起」收回。按住第一行可拖动，位置会被记住。
金价数据来自京东金融「浙商银行积存金」公开实时报价接口（无需登录、无需密钥）。 程序只读取行情，不会上传待办内容或任何个人数据。完全不想联网的话，用 pythonw.exe todo_dock.py --nogold 启动即可关闭行情。

二、两类待办怎么建

近期待办
点面板上的 「+ 近期」或日历导航行的「近期」 → 底部标题变成「近期待办 · 不设日期」→ 在输入框直接写内容按回车。这类待办不绑定任何日期、不提醒，标签显示「近期」， 随时做随时勾。命令行里 todo.py add "标题"（不带 --due）也是这一类。
日期待办
点月历里任意日期（或「今天」）→ 下方标题变成那天 → 输入内容按回车。这类待办可设提醒时刻与「当天 / 提前1天」开关。
排序
最近待办按 紧急（逾期 / 今天 / 明天）→ 近期（不设日期）→ 之后（有确定日期） 排列； 近期待办不会盖住今天到期的急事，也不会沉到最底。
互相转换
todo.py setdue 3 2026-11-20 给近期待办补日期； todo.py setdue 3 none 去掉日期改回近期待办。
长标题看全文
列表里放不下的标题会以 … 收尾； 把鼠标停在这条待办上约 0.3 秒，旁边会弹出浅色气泡显示完整标题（自动换行， 下面还标着「近期」或日期时刻），鼠标移开自动消失。短标题本来就完整，不会弹气泡。 列表右侧的「近期 / 日期」标签始终完整显示，不会被长标题挤掉。 提醒弹窗里的长标题也会自动换行展示全文。
完成 / 删除
每条左边的 ○ 点一下标记完成，右边 × 删除。
日历标记
有待办的日期下方有蓝点，今天浅蓝底，选中日深蓝底。 切到「近期」模式时不再有选中日，只保留今天高亮。

三、提醒规则（仅日期待办）

提醒时刻
每条可设 HH:MM（默认 09:00），在输入框下方填写。
当天 / 提前一天
截止日当天、前一天的同一时刻各弹一次； 两个勾选框可分别开关，都不勾 = 不提醒。近期待办没有日期，这几个控件会变灰不可用。
试一次提醒
面板右下角「试一次提醒」立即弹一条演示提醒，确认弹窗和提示音正常。
补发
到点时没开机，开机后 20 小时内补发一次； 每条提醒只弹一次（记录在 notified）。弹窗按钮：「标记完成」归档，「知道了」只关窗，60 秒自动收起。
提醒依赖挂件常驻。已配置开机自启；手动关掉后，双击桌面上的 待办胶囊.vbs 即可重新挂上。

四、命令行（可选）

近期待办
todo.py add "买猫粮"（不带 --due 即不设日期）
带日期新增
todo.py add "交房租" --due 2026-11-16 --time 09:00
提醒组合
--remind both|day|eve|none
改 / 去日期
todo.py setdue 3 2026-11-20 --time 14:00、 todo.py setdue 3 none
查金价
todo.py gold 立刻显示最新价、涨跌、昨收、报价时间； todo.py status 会顺带显示金价缓存。
看清单
todo.py list / list --all / list --full（长标题不截断，显示全文）； done、remove、progress、rename 用法不变。
启停
todo.py status、install、start、 stop、autostart on|off|status；start --legacy 切回旧版进度条界面。

五、文件都在哪

  • 程序与数据：~/.workbuddy/todo-widget/，主程序 todo_dock.py，待办数据 data.json。
  • 金价缓存：gold_cache.json（单独存放，不写 data.json，不会触发待办热加载）；运行日志 dock.log。
  • 待办命令行改完约 0.3 秒自动刷新，不用重启窗口。
  • 日期字段：due、time、remind、notified； 近期待办没有这些字段，旧数据也兼容。
  • 删除待办前有单份滚动备份 data.json.backup-cli。
